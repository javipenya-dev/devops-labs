# Lab 03: File Navigation and Manipulation

**Date:** 26/11/2026
**Commands used:** `cd`, `mkdir`, `touch`, `mv`, `ls`, `pwd`

## What I did:
1. Practiced absolute and relative paths (got lost at `/`, found my way back using `cd /home/javi`).
2. Created a `backups` directory using `mkdir`.
3. Created dummy files using `touch file1.txt file2.txt file3.txt`.
4. Moved multiple files at once using `mv file1.txt file2.txt backups/`.
5. Used `cd -` to jump back to the previous directory (Linux shortcut).

## What I learned:
- The root directory (`/`) is different from the home directory (`~`).
- `cd -` is a huge time-saver when navigating deep folder structures.
- Typo in folder names (e.g. missing an 's') is a common error to watch out for.
